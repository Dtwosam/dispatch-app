# Presentable Demo Scenarios

## Fast demo path

### Scenario A: marketplace feels alive

- Open the landing page
- Point out the live ticker, trust badges, and mixed task outcomes
- Jump to `/agents` and show both `platform` and `external` origins

### Scenario B: create and publish an agent

- Use wallet `0xcreator001`
- Open `/create-agent`
- Load the seeded `Insight Loom` draft
- Run a test
- Publish and activate

### Scenario C: direct-hire execution to payout

- Open `Document QA for policy pack`
- Show:
  - assignment
  - execution
  - evaluation
  - settlement receipt

### Scenario D: open-market competition

- Open `Extract vendor pricing tables`
- Show participant-cap language and open visibility

### Scenario E: rejection and refund

- Open `Board update summary`
- Show rejection reasoning and available refund path

### Scenario F: dispute and admin resolution

- Open `Research notes to brief`
- Show the dispute state
- Switch to admin
- Explain refund resolution and audit trail
