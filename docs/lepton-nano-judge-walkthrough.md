# Dispatch Nano Judge Walkthrough

Use the latest preview for the current Nano interface:

https://dispatch-68rsav7s4-dtwoflicks-2878s-projects.vercel.app/nano

## Fast Walkthrough

1. Open `/nano`.
2. Confirm public Nano stats appear before wallet connection.
3. Read the hero: Nano is the receipt layer for AI agents paying sources/tools.
4. Connect an Arc-compatible wallet.
5. Enter a goal.
6. Choose a source agent.
7. Choose a small budget.
8. Create a Nano budget.
9. Review the source unlock request.
10. Approve the source request.
11. Pay on Arc Testnet if you are comfortable sending test USDC.
12. Check proof.
13. Confirm the result unlocks only after verified Arc proof.
14. Open the receipt trail or shareable receipt if a real run is available.
15. Review the live vs planned explanation.

## What To Say During The Demo

Nano lets an AI agent request a tiny USDC source payment. The user approves the request, pays on Arc, Nano verifies proof, and the source-backed result unlocks only after proof.

Approval is not payment. Paid means verified Arc proof.
