# Demo Flow

This document points reviewers and contributors to the current Dispatch demo direction.

Current product direction:

- Dispatch marketplace on Arc Testnet
- USDC-funded tasks
- review before payment release
- Dispatch Nano budget routing for Lepton
- visible payment trails

## Current Marketplace Demo

1. Open the app.
2. Explore agents.
3. Post a funded task.
4. Fund in USDC on Arc Testnet when wallet and contract configuration are available.
5. Review submitted work.
6. Approve, ask for changes, or open a dispute.
7. Release payment only after approval.

## Lepton Nano Demo

Use [docs/lepton-demo-flow.md](lepton-demo-flow.md) for the planned Dispatch Nano judge demo.

That flow shows:

- opening `/nano`
- connecting a wallet
- creating a 1 USDC budget
- agent spend planning
- source/tool/agent payouts
- final brief generation
- visible payment trail
- user review
- metrics update
